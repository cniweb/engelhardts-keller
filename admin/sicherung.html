Server-Sicherheit & .htaccess Passwortschutz

2-Stufen-Sicherheitskonzept
1
Webserver-Ebene (.htaccess)

Im Ordner admin/ liegt die Datei .htaccess. Wenn Sie Ihre Website auf einem Apache-Webserver betreiben, können Sie den serverseitigen HTTP Basic Auth Passwortschutz aktivieren, indem Sie den Pfad zu Ihrer .htpasswd eintragen.

Eine Musterdatei .htpasswd.example mit Hinweisen zur Passworterstellung ist ebenfalls im Ordner admin/ hinterlegt.

2
Client-Ebene (JavaScript-Fallback)

Sollte der Server noch nicht für .htaccess konfiguriert sein (z. B. auf lokalen Testumgebungen oder Windows-Webservern), schützt die integrierte JavaScript-PIN-Sperre als zuverlässiger Fallback.

Die Anmeldung bleibt für Ihre Browser-Sitzung über alle 6 Seiten hinweg aktiv, bis Sie auf „Abmelden“ klicken.
